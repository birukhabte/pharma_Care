🚀 HOW TO RUN MIGRATION
═══════════════════════════════════════════════════════════════

1. Navigate to server directory:
   $ cd server

2. Run migration:
   $ npm run migrate

3. Restart server:
   $ npm start

4. Test endpoints:
   $ ./test-migration.sh

📝 API ENDPOINTS
═══════════════════════════════════════════════════════════════

Customers:
  GET    /api/customers              - List all
  GET    /api/customers/:id          - Get one
  POST   /api/customers              - Create
  PUT    /api/customers/:id          - Update
  DELETE /api/customers/:id          - Delete
  PATCH  /api/customers/:id/loyalty  - Update points

Suppliers:
  GET    /api/suppliers              - List all
  GET    /api/suppliers/:id          - Get one
  POST   /api/suppliers              - Create
  PUT    /api/suppliers/:id          - Update
  DELETE /api/suppliers/:id          - Delete

Prescriptions:
  GET    /api/prescriptions          - List all
  GET    /api/prescriptions/:id      - Get one
  POST   /api/prescriptions          - Create
  PUT    /api/prescriptions/:id      - Update
  PATCH  /api/prescriptions/:id/fill - Fill prescription
  DELETE /api/prescriptions/:id      - Delete

Purchase Orders:
  GET    /api/purchase-orders            - List all
  GET    /api/purchase-orders/:id        - Get one
  POST   /api/purchase-orders            - Create
  PUT    /api/purchase-orders/:id        - Update
  PATCH  /api/purchase-orders/:id/approve - Approve
  PATCH  /api/purchase-orders/:id/receive - Receive
  DELETE /api/purchase-orders/:id        - Delete

Stock Movements:
  GET    /api/stock-movements                    - List all
  GET    /api/stock-movements/:id                - Get one
  POST   /api/stock-movements                    - Create
  GET    /api/stock-movements/medicine/:id/history - History

Notifications:
  GET    /api/notifications              - Get user notifications
  PATCH  /api/notifications/:id/read     - Mark as read
  PATCH  /api/notifications/read-all     - Mark all as read
  DELETE /api/notifications/:id          - Delete

Settings:
  GET    /api/settings                   - Get settings
  PUT    /api/settings                   - Update all
  PATCH  /api/settings/:section          - Update section

Audit Logs:
  GET    /api/audit-logs                 - List all (admin)
  GET    /api/audit-logs/:id             - Get one
  GET    /api/audit-logs/user/:userId    - User activity
  GET    /api/audit-logs/entity/:entity/:id - Entity history
